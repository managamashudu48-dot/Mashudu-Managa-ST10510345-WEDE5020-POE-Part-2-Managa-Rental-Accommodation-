# Managa Rental Accommodation

## Project Description

Managa Rental Accommodation is a website designed to provide information about available rental accommodation. The website allows visitors to learn about the accommodation, view available services, submit an enquiry and find contact information.

## Project Goals

- Provide clear information about rental accommodation.
- Make it easy for users to navigate between pages.
- Allow users to submit an accommodation enquiry.
- Create a responsive website that works on desktop, tablet and mobile devices.
- Use HTML and external CSS to create a professional website.

## Website Pages

1. Home
2. About Us
3. Services
4. Enquiry
5. Contact
6. Sitemap

## Technologies Used

- HTML5

- Visual Studio Code

## Features

- Navigation menu
- Accommodation information
- Accommodation image
- Services information
- Enquiry form
- Contact information
- Sitemap
- Responsive design
- Mobile and tablet layouts

## Responsive Design

The website uses CSS media queries to adapt the layout for:

- Desktop screens
- Tablet screens
- Mobile screens

Relative units such as %, rem and vw are used to help the website adapt to different screen sizes.

## Part 2 Testing

The website was tested on different screen sizes to check that the responsive design works correctly.

### Desktop Testing
- Navigation links were tested.
- Images were checked.
- The layout was checked on a large screen.
- The enquiry form was tested.

### Tablet Testing
- The layout was checked at tablet size.
- Cards were checked to make sure they fit correctly.
- Images were checked for proper sizing.

### Mobile Testing
- Navigation changes to a vertical layout.
- Cards change to one column.
- The enquiry form fits the screen.
- Images remain responsive.
- Tables can be viewed without breaking the page.

## Responsive Images

Responsive images were implemented using:

- `srcset`
- `sizes`
- `<picture>`
- Different image sizes for small, medium and large screens.
